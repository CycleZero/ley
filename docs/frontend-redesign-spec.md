# 前端重设计 · 正式设计规范（Design Spec v1.0）

> 状态：**定稿基准**（2026-09-06）
> 关联视觉稿：`/tmp/opencode/mock-d1-blue-tech/`（v2 `index.html` = 干净蓝白基准；`index-v4.html` = 上半留白终版；`index-lineart.html` = 已废弃的二次元线稿尝试）
> 范围：仅规范**视觉体系与首页布局**；页面/组件级的 React 落地在后续任务。

---

## 1. 设计方向（一句话）

**近白底 + 实白卡 + 蓝白主色 + 数据面板语言（等宽数字/网格/刻度）= 蓝白科技 · 干净留白**。与上一版（Cloudreve 灰底白卡）完全不同，属于推倒重来。

### 已否决方向（记录，避免回潮）

| 方向 | 否决原因 |
|---|---|
| 粉紫马卡龙玻璃拟态（第1轮 A/B/C 三稿） | 用户明确"太紫" |
| 深蓝霓虹赛博（D2 NIGHT DECK） | 用户选浅色主推；NIGHT DECK 仅保留作暗色模式参考，非首选 |
| 二次元线稿贴饰（v3 线稿猫/站娘/线稿封面） | 用户"并不满意"，明确"先不考虑二次元问题" |

## 2. 色彩规范

### 2.1 主色板（蓝白，~88% 面积）

| Token 名 | 值 | 用途 |
|---|---|---|
| `--bg-page` | `#fafcff → #ffffff`（近白微渐变） | 页面背景 |
| `--bg-panel` | `#ffffff` 实底 | 卡片主体（**非玻璃透色**） |
| `--accent-blue` | `#3b82f6` | 主蓝：数据、选中、导航高亮、链接 |
| `--blue-soft` | `#7db4f0` | 光斑/辅助蓝 |
| `--cyan` | `#38bdf8` | 天青：状态光、小点缀 |
| `--ink` | `#1d3a5f` | 主文字（深蓝灰，不用纯黑） |
| `--ink-secondary` | `#51799f` | 次级文字 |
| `--ink-tertiary` | `#8aa8c4` | 弱文字/占位 |
| `--border-card` | `rgba(30,80,160,0.10)` | 卡片描边（淡蓝灰，清晰可见） |

### 2.2 点缀色（≤8% 面积，提亮不抢戏）

| Token 名 | 值 | 用途（限制） |
|---|---|---|
| `--amber` | `#f0b35e` | 琥珀金：仅太阳、播放钮、1-2 个数字渐变点缀 |
| `--mint` | `#5eead4` | 薄荷青：chip、状态圆点、柱状图尾段 |

> **纪律**：点缀单元实体 ≤ 40×40px；粉/紫只在"关于我"头像渐变上允许（≤46px）；**禁止**整块粉色/紫色背景。

### 2.3 暗色模式（后续实现参考）

> 沿用 D2 NIGHT DECK 思路，但**浅色为主推**，暗色为可选模式的第二套 token（下阶段再细化，防止现在过度设计）。

## 3. 卡片材质规范（体系核心）

**核心变化**：从"玻璃透色"改为"**实白卡 + 描边 + 轻阴影**"——这是解决前稿"脏、糊"的关键。

```css
.card {
  background: rgba(255, 255, 255, 0.94);
  border: 1px solid rgba(30, 80, 160, 0.10);
  border-radius: 22px;
  box-shadow: 0 4px 16px rgba(50, 80, 140, 0.06);
}
.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 8px 28px rgba(50, 80, 140, 0.12), 0 0 24px rgba(59, 130, 246, 0.18);
}
```

- **不用 backdrop-filter 透色**（已删）；层次全靠 描边 + 轻阴影 立出
- 圆角统一 22px（卡片）/ 18px（chip、内嵌小块）
- 动效：hover 上浮 4px + 微弱蓝光，`transition: all .25s ease-out`，尊重 `prefers-reduced-motion`

## 4. 布局规范

### 4.1 首页「上半留白」终版（v4，用户最终要求）

```
┌─────────────────────────────────────────────┐
│ 顶部导航条（h-64px，sticky，近白 60% 透明+blur）│
│                                             │
│       ▲ 约 112px 纯白呼吸区（padding-top 88px）│
│                                             │
│  {site_title}（标题 56-72px 深蓝，#3b82f6 主笔触，读后端配置）│
│  {英文 kicker 占位，不固定}                              │
│  {site_subtitle}（副标，ink-secondary）                 │
│       ▼ 48px 分隔                           │
│                                             │
│  [卡片流起点 ~y400，上半部 50% 为留白+标题]   │
└─────────────────────────────────────────────┘
```

- **留白纪律**：导航→标题区 ≥96px 纯白；标题区→卡片流 ≥48px；首屏 1280×800 上半 40% 为"导航+留白+标题"（不放卡片）
- **响应式**：≥980px 保留左侧竖排胶囊导航（64px 宽，6 图标）；<980px 收为顶部/底部导航；<768px 卡片流单列
- 主内容区 max-width 1200px 居中（1920 下居中延展；1280 下两侧留 24px 呼吸边距）

### 4.2 Bento 信息面板（首页卡片流）

CSS Grid `repeat(12, 1fr)`，11 卡 span 错落（现状）：问候卡 span4×2 行领衔，天气/社交/站点统计/最近文章/日历/标签云/音乐/关于我/留言/状态卡。

**卡片清单（保持内容，React 落地时再定具体 span）**：问候、天气、社交（B站/GitHub/Twitter/Instagram/Steam）、站点统计（40 文章 / 08 分类 / 56 标签 + 迷你柱状图）、最近文章（3 篇）、日历（今日高亮圆环）、标签云、正在播放、关于我、留言、欢迎气泡。

### 4.3 科技感元素（克制清单，已从 v2/v3 噪音减量）

| 元素 | 现状 | 允许度 |
|---|---|---|
| 背景网格线 | 双层交叉 repeating-linear-gradient `rgba(59,130,246,0.04)` | 保留（极淡） |
| hero 底部刻度尺 | 细线刻度（LAT 伪文本已删） | 保留 |
| 等宽数据字体 | 数据/时间/统计全 mono | 保留（核心科技语言） |
| 粒子 | 16 个极淡小点 | 保留（禁增） |
| 卡片角标/伪代码标签 | 仅问候卡 1 处角标 | 保留（禁增，去 AI 化） |
| 漂浮柔光球 | **已删除** | 禁回 |

> **去 AI 感纪律**：只保留 1-2 处高级装饰；"到处都是装饰"= 失败。

## 5. 字体规范

- **中文**：`"PingFang SC", "Microsoft YaHei", sans-serif`
- **标题英文/数据**：`ui-monospace, "JetBrains Mono", monospace`（数字、时间、统计、KICKER）
- **hero 标题**：主题字用中文字体重磅（700/900），主色蓝 `#3b82f6` 到深蓝 `#1d3a5f` 渐变笔触；英文副标字母间距 0.08~0.12em 拉宽（科技感），不用草书；文字内容读 `site_title`
- **正文**：15px / line-height 1.7；卡片标题 16-18px / 600

---

## 6. 标题与标识（可自定义，非硬编码）

**核心规则：所有站点标题/副标题/页脚文字均从后端 `site_config` 读取（`site_title` / `site_subtitle` / `footer_text`），用户在后端站点配置页随时修改，前端不做任何硬编码站名。**

- 首页 hero 大标题 = `site_title`（读后端配置；缺失时降级为"我的博客"等中性占位）
- 英文 kicker = 占位空或站点副标 （不写死 `BLUE · ISLE`——那是视觉稿演示占位）
- 页脚 = `footer_text`（后端可编辑）
- 视觉稿中的「星屿 / BLUE · ISLE」**仅为演示占位**，正式实现以用户配置为准

## 7. 落地映射（React 侧预期）

1. **globals.css 重写**：上述 token 全量替换现 Cloudreve 变量（`--bg-global`/`--bg-card`/`--accent` 等作废），新增 `@theme` 语义类（`bg-page`/`card`/`accent`…）
2. **UI 基元**：Button（primary=accent-blue 实底白字；danger 保留红）、Card（实白描边新规范）、Input/Modal/Badge 跟随 token，删掉裸 tailwind 色 usage
3. **布局**：DefaultLayout 重做（顶栏 + 左侧胶囊导航 + Bento 首页）；AdminLayout 后续同风格化
4. **数据**：复用现 hooks/api-client（不动数据层），仅样式与结构
5. **暗色**：第二阶段做（NIGHT DECK token 映射），首版只交付浅色

---

## 8. 验收标准（对照本 spec）

- [ ] 全站无粉/紫大面积背景；蓝白主导 ≥85%
- [ ] 卡片无透色，描边（0.10 蓝灰）+ 轻阴影层次清晰
- [ ] 首屏上半 40% 为留白+标题区（v4 布局）
- [ ] 科技感元素总量 ≤ v4 现状（不增装饰）
- [ ] tsc + 单测 + lint 全绿、无外部资源硬依赖
